# 🛒 E-Commerce Platform

A modern full-stack E-Commerce application built with Next.js, MongoDB, NextAuth, Razorpay, and Cloudinary. The platform provides a seamless shopping experience with secure authentication, online payments, product management, and responsive design.

---

## ✨ Features

### 🔐 Authentication & Authorization
- Secure user authentication with NextAuth
- Login and registration system
- Protected routes
- Session management
- Role-based access control (Admin/User)

### 🛍️ Product Management
- Browse products
- Product details page
- Product categories
- Product search and filtering
- Product image management with Cloudinary

### 🛒 Shopping Experience
- Add to cart
- Update cart quantity
- Remove items from cart
- Persistent shopping cart
- Responsive UI for all devices

### 💳 Payment Integration
- Secure payments using Razorpay
- Order creation and tracking
- Payment verification
- Order confirmation

### 📦 Order Management
- Place orders
- View order history
- Track order status
- Manage customer orders

### ☁️ Cloud Storage
- Cloudinary integration
- Optimized image delivery
- Secure image uploads

### 📱 Responsive Design
- Mobile-first design
- Tablet support
- Desktop optimized
- Modern UI/UX
